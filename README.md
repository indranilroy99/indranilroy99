### What I build

**Agentic SOC** — multi-agent AI systems that triage alerts, run threat hunts, and drive response with little to no human touch. Cutting analyst noise, not adding to it.

**Detection engineering** — rules mapped to MITRE ATT&CK, tuned for signal over volume. Coverage up, false positives down.

**Threat intelligence** — pipelines that turn indicators into detections, and MISP wired into the tools analysts and agents actually use.

**Open-source security tooling** — I ship most of what I build publicly: MCP servers that wire threat intel into AI agents, security scanners for AI-agent repos, Slack-native security agents, SOC training labs, and detection-translation engines. Pinned repos below.
